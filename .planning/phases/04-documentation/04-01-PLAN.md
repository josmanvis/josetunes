Replace the current README stub with a comprehensive README containing these sections in order:

1. **Header**: Project name "JoseTunes" with tagline "Cross-platform desktop audio downloader". Mention it downloads from YouTube and SoundCloud in FLAC or MP3 format. Include version badge showing v0.1.0.

2. **Features** (brief bullet list):
   - Batch download audio from YouTube and SoundCloud
   - FLAC and MP3 format support
   - Cross-platform: macOS (arm64 + Intel), Windows, Linux
   - Simple paste-and-download workflow

3. **Prerequisites**:
   - **yt-dlp** is required (JoseTunes uses it under the hood for audio extraction)
   - Installation commands per platform:
     - macOS: `brew install yt-dlp`
     - Windows: `winget install yt-dlp` or `scoop install yt-dlp`
     - Linux: `sudo apt install yt-dlp` or `pip install yt-dlp`
   - Link to yt-dlp GitHub: https://github.com/yt-dlp/yt-dlp

4. **Installation** with three methods:

   a. **Homebrew (macOS)**:
      ```
      brew install josmanvis/josetunes/josetunes
      ```
      Note: Since the app is unsigned, after first install run:
      ```
      xattr -cr /Applications/josetunes.app
      ```

   b. **npm (cross-platform)**:
      ```
      npx josetunes
      ```
      This downloads and launches the platform-appropriate installer. Requires Node.js >= 16.

   c. **Direct Download**:
      Download the latest release for your platform from [GitHub Releases](https://github.com/josmanvis/josetunes/releases/latest):
      - macOS: `.dmg` (arm64 or x64)
      - Windows: `.msi`
      - Linux: `.deb` or `.AppImage`

5. **Usage**:
   - Open JoseTunes
   - Paste a YouTube or SoundCloud URL into the search box
   - Select audio format (FLAC or MP3)
   - Click "Download All" to start downloading
   - Files are saved to `~/Downloads/`

6. **Development** (brief, for contributors):
   ```
   bun install
   bun run tauri dev
   ```
   Requires: Rust toolchain, Node.js, Bun, Tauri v1 prerequisites.

7. **License**: MIT

Keep the tone concise and scannable. Use code blocks for all commands. No unnecessary prose.
