<task type="auto">
  <name>Task 2: Add automated cask update workflow to tap repository</name>
  <files>
    ../homebrew-josetunes/.github/workflows/update-cask.yml
  </files>
  <action>
    Create `.github/workflows/update-cask.yml` in the homebrew-josetunes repository with:

    Trigger: `workflow_dispatch` with input `version` (string, required, description: "Release version without v prefix")

    Job: `update-cask` on `ubuntu-latest` with `permissions: contents: write`

    Steps:
    1. `actions/checkout@v4`
    2. "Wait for release assets" step: Retry loop (5 attempts, 30s sleep between) checking HTTP status of the aarch64.dmg URL. Use `curl -sL -o /dev/null -w "%{http_code}"` against `https://github.com/josmanvis/josetunes/releases/download/v${VERSION}/josetunes_${VERSION}_aarch64.dmg`. Break on 200 or 302. Fail with error if all attempts exhausted.
    3. "Compute SHA256 checksums" step: Download both DMGs via `curl -sL` piped to `shasum -a 256 | awk '{print $1}'`. Store in `SHA_ARM` and `SHA_INTEL` env vars via `$GITHUB_ENV`. Also store `VERSION`.
    4. "Generate cask file" step: Use heredoc (`cat > Casks/josetunes.rb << 'CASK'`) to write the COMPLETE cask file. The heredoc must use single-quoted delimiter ('CASK') to prevent shell variable expansion inside Ruby interpolation (`#{version}`). Then use `sed -i` to substitute the SHA256 placeholders and version with the actual env var values AFTER the heredoc writes the template.
       - Write the cask template with literal `PLACEHOLDER_ARM_SHA256`, `PLACEHOLDER_INTEL_SHA256`, and `PLACEHOLDER_VERSION` strings
       - Then run: `sed -i "s/PLACEHOLDER_ARM_SHA256/${SHA_ARM}/" Casks/josetunes.rb`
       - Then run: `sed -i "s/PLACEHOLDER_INTEL_SHA256/${SHA_INTEL}/" Casks/josetunes.rb`
       - Then run: `sed -i "s/PLACEHOLDER_VERSION/${VERSION}/" Casks/josetunes.rb`
    5. "Commit and push" step: Configure git user as `github-actions[bot]` with email `github-actions[bot]@users.noreply.github.com`. Stage `Casks/josetunes.rb`, commit with message "Update josetunes to ${VERSION}", and push.

    Important: The heredoc delimiter MUST be quoted ('CASK') so that `#{version}` Ruby interpolation is preserved literally in the file, while shell variables like `${SHA_ARM}` are substituted via sed after the file is written.
  </action>
  <verify>
