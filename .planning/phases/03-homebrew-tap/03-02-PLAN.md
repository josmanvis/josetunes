<task type="auto">
  <name>Task 1: Add Homebrew tap trigger step to release job</name>
  <files>.github/workflows/main.yml</files>
  <action>
    Add a new step at the END of the `release` job in `.github/workflows/main.yml`, AFTER the "Create GitHub Release" step.

    The step should be:
    ```yaml
    - name: Trigger Homebrew tap update
      run: |
        VERSION=${GITHUB_REF_NAME#v}
        gh workflow run update-cask.yml \
          -f version=${VERSION} \
          -R josmanvis/homebrew-josetunes
      env:
        GITHUB_TOKEN: ${{ secrets.HOMEBREW_TAP_TOKEN }}
    ```

    Important details:
    - This goes in the `release` job (NOT in a new job) because it needs to run AFTER the release is created
    - Use `secrets.HOMEBREW_TAP_TOKEN` (NOT `secrets.GITHUB_TOKEN`) -- the default token cannot trigger workflows in other repos
    - The version strips the `v` prefix using bash parameter expansion `${GITHUB_REF_NAME#v}`
    - `-R josmanvis/homebrew-josetunes` targets the tap repository
    - `-f version=` passes the version as a workflow_dispatch input

    Do NOT modify any other part of the workflow file. Only append this step to the release job.
  </action>
  <verify>
    - `grep "Trigger Homebrew tap update" .github/workflows/main.yml` returns a match
    - `grep "HOMEBREW_TAP_TOKEN" .github/workflows/main.yml` returns a match
    - `grep "homebrew-josetunes" .github/workflows/main.yml` returns a match
    - The step appears AFTER the "Create GitHub Release" step in the file
  </verify>
  <done>
    The release job now triggers the Homebrew tap update workflow after creating a GitHub Release. The full automation chain is: tag push -> build -> release -> trigger tap update -> tap computes SHA256 and updates cask.
  </done>
