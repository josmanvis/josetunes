  <action>
Create `packages/josetunes/package.json` with the following exact content:

```json
{
  "name": "josetunes",
  "version": "0.1.0",
  "description": "Cross-platform desktop audio downloader - installer",
  "bin": {
    "josetunes": "bin/josetunes.js"
  },
  "files": [
    "bin/",
    "package.json"
  ],
  "keywords": ["audio", "downloader", "youtube", "soundcloud", "desktop", "tauri"],
  "license": "MIT",
  "author": "Jose",
  "repository": {
    "type": "git",
    "url": "https://github.com/josmanvis/josetunes.git",
    "directory": "packages/josetunes"
  },
  "engines": {
    "node": ">=16.0.0"
  }
}
```

Key decisions:
- No `dependencies` field (zero deps, all Node.js built-ins)
- `files` includes only `bin/` and `package.json` (minimal publish footprint)
- `engines.node >= 16` because the CLI uses only stable built-in APIs
- `repository.directory` points to monorepo subdirectory
- Version 0.1.0 matches Cargo.toml source of truth

  </verify>
