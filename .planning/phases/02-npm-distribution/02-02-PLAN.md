Replace the contents of `packages/josetunes/bin/josetunes.js` with the complete CLI implementation. Use ONLY Node.js built-in modules (https, fs, path, os, crypto, child_process). Zero external dependencies.

The script must include these sections in order:

**1. Header and imports:**
```javascript
#!/usr/bin/env node
'use strict';

const https = require('https');
const fs = require('fs');
const path = require('path');
const os = require('os');
const crypto = require('crypto');
const { execSync, spawn } = require('child_process');
```

**2. Constants:**
- `VERSION` read from `require('../package.json').version`
- `GITHUB_REPO` = `'josmanvis/josetunes'`
- `PLATFORM_MAP` object mapping `${process.platform}-${process.arch}` keys to objects with:
  - `darwin-arm64`: `{ file: 'josetunes_VERSION_aarch64.dmg', label: 'macOS (Apple Silicon)' }`
  - `darwin-x64`: `{ file: 'josetunes_VERSION_x64.dmg', label: 'macOS (Intel)' }`
  - `linux-x64`: `{ file: 'josetunes_VERSION_amd64.deb', label: 'Linux (Debian/Ubuntu)' }`
  - `win32-x64`: `{ file: 'josetunes_VERSION_x64-setup.exe', label: 'Windows' }`
  - File names use template literals with VERSION interpolated (e.g., `` `josetunes_${VERSION}_aarch64.dmg` ``)

**3. Platform check:**
- Build `platformKey` from `process.platform` + `-` + `process.arch`
- Look up in PLATFORM_MAP
- If not found: print unsupported message with supported platforms list, print manual download URL, exit(1)

**4. `download(url, dest)` function:**
- Returns a Promise
- Uses `https.get` with `{ headers: { 'User-Agent': 'josetunes-npm' } }`
- Handles 301/302 redirects by recursively calling download with `response.headers.location`
- On 200: pipes to `fs.createWriteStream(dest)`
- Shows progress with `process.stdout.write('\r  Downloading... XX%')` using content-length header
- Rejects on non-2xx/3xx status codes
- Rejects on request error

**5. `verifyChecksum(filePath, expectedHash)` function:**
- Reads file, computes SHA256 hash using `crypto.createHash('sha256')`
- Compares against expectedHash
- Returns boolean

**6. `getExpectedChecksum(version, filename)` function:**
- Downloads `SHA256SUMS.txt` from the same release
- URL: `https://github.com/${GITHUB_REPO}/releases/download/v${version}/SHA256SUMS.txt`
- Parses the file to find the hash for the given filename
- SHA256SUMS.txt format: `hash  filename` (two spaces between)
- Returns the hash string, or null if not found
- On download failure: return null (checksum verification is best-effort, not blocking)

**7. `launchInstaller(filePath)` function:**
- Switch on `process.platform`:
  - `darwin`: `execSync('open "' + filePath + '"')` then print "DMG opened! Drag JoseTunes to your Applications folder."
  - `win32`: `spawn(filePath, [], { detached: true, stdio: 'ignore' }).unref()` then print "Installer launched! Follow the installation wizard."
  - `linux`: Print `sudo dpkg -i "path"` instruction and `sudo apt-get install -f` for dependency fixes. Also set executable bit with `fs.chmodSync(filePath, 0o755)`.

**8. `main()` async function:**
- Print header: "JoseTunes vVERSION Installer" and "Platform: label"
- Build asset URL and destPath (in `os.tmpdir()`)
- Call `download(assetUrl, destPath)`
- Call `getExpectedChecksum(VERSION, platform.file)` -- if hash returned, verify with `verifyChecksum`. If mismatch, warn but continue (print warning, do not exit).
- Call `launchInstaller(destPath)`
- Catch block: print error message and manual download URL, exit(1)

**9. Invoke:** `main();`

IMPORTANT constraints:
- Do NOT use `fetch` (not available in Node 16)
- Do NOT auto-sudo on Linux (print instructions only)
- Do NOT block terminal on Windows (spawn detached + unref)
- Handle at least 2 levels of redirects (GitHub sometimes does double redirect)
- Use `\r` for progress overwrites (single line, no scrolling)
